# 📘 Catatan Belajar C — Sesi 2: Variabel & Format Specifier

## 1. Apa itu Variabel?
Variabel adalah "wadah" atau "toples" untuk menyimpan nilai di dalam memori komputer. 
Contoh: `int umur = 20;`

- `int` = Tipe data bilangan bulat (Integer).
- `umur` = Nama variabel (bebas, tidak boleh pakai spasi).
- `=` = Tanda Assign (memberi nilai).
- `20` = Value (nilai yang disimpan).

## 2. Format Specifier (%d)
Untuk mencetak isi variabel angka bulat ke layar, kita menggunakan `%d` (singkatan dari *decimal*).
Contoh: `printf("Umur saya %d tahun\n", umur);`

- `%d` adalah "lubang" kosong.
- `umur` di ujung kanan adalah isi yang akan dimasukkan ke lubang tersebut.

## 3. Operasi Aritmatika
Kita bisa menghitung langsung menggunakan variabel.
- Tambah: `+`
- Kurang: `-`
- Kali: `*`
- Bagi: `/`

Contoh: `int hasil = a + b;`

## 4. Kosakata Baru
1. Assign: Memberi nilai
2. Value: Nilai
3. Integer: Bilangan bulat
4. Format Specifier: Penentu format (seperti %d)
5. Initialize: Mengisi nilai awal
6. Subtract: Mengurangi
7. Add: Menambah
8. Result: Hasil
9. Variable: Wadah nilai
10. Compiler: Penerjemah kode
